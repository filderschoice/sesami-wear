# サポート情報

Sesami Wear の利用者向けに、アップデート内容の確認先と問い合わせ方法をまとめています。
操作方法は [利用ガイド](USER_GUIDE.md)、インストール手順は [INSTALL.md](INSTALL.md) を参照してください。

> 本アプリは個人による非公式アプリです。CANDY HOUSE株式会社とは提携・協力関係がなく、
> 同社のサポート対象外です。Sesame本体・Hub・純正アプリの不具合は同社へお問い合わせください。

## アップデート内容の確認先

更新があった場合は、次の場所で内容を確認できます。いずれも同じ内容を掲載します。

| 確認先 | URL | 内容 |
| --- | --- | --- |
| リリースノート（一次情報） | [docs/RELEASE_NOTES.md](RELEASE_NOTES.md) | 全バージョンの新機能・改善・修正・既知の問題 |
| GitHub Releases | <https://github.com/filderschoice/sesami-wear/releases> | 各リリースの内容と配布ファイル |
| Google Play の「新機能」 | 公開後にストアページへ掲載 | 直近リリースの要約（500文字以内） |

- **どこを見ればよいか迷う場合は、リリースノートを見てください。** 過去分を含む全履歴が
  1ページにまとまっています。
- GitHub Releases を「Watch」しておくと、新しいリリースの通知を受け取れます
  （リポジトリ右上の Watch → Custom → Releases）。

## アップデート方法

- **Google Play経由で導入した場合**（公開後）: 通常のアプリと同様に自動更新されます。すぐに更新したい
  場合は、Play ストアのアプリページから「更新」をタップしてください。ウォッチ側のアプリは、
  スマートフォン側の更新にあわせて配信されます。
- **ローカルビルドを導入した場合**: 最新のソースコードを取得して再ビルド・再インストールしてください
  （手順は [INSTALL.md](INSTALL.md)）。資格情報は再入力不要です（アプリのデータを消去した場合を除く）。

## 現在の配布状況

**Google Playへは未公開です（2026-09-05時点）。** 現時点で利用できるのは、リポジトリから
ローカルビルドしてインストールする方法のみです。公開状況が変わった場合は、本ファイルと
リリースノートを更新します。

## 問い合わせ・報告の窓口

### 不具合・要望・質問

GitHub Issues をご利用ください。目的別のテンプレートを用意しています。

- <https://github.com/filderschoice/sesami-wear/issues/new/choose>
  - **不具合の報告**: 期待どおりに動作しない場合
  - **機能の要望・改善提案**: 新機能や改善の提案
  - **使い方の質問**: セットアップや操作方法の質問

GitHubアカウントをお持ちでない場合は、メール（<filderschoice.release@gmail.com>）でも受け付けます。

### 脆弱性の報告

セキュリティ上の問題は、**公開Issueへ投稿せず** [SECURITY.md](../SECURITY.md) の手順に従って
非公開の経路でご報告ください。

### 報告時のお願い

- **apikey / secretKey / uuid を含めないでください。** ログやスクリーンショットに写り込んでいないか
  送付前にご確認ください。これらはSesameを施錠・解錠できる情報です。
- 次の情報があると調査が進みやすくなります。
  - アプリのバージョン（スマートフォンの「設定 > アプリ > Sesami Wear」で確認できます）
  - スマートフォン・スマートウォッチの機種とOSバージョン
  - 再現手順と、実際に起きたこと・期待した動作
  - 再現性（毎回／ときどき／一度だけ）
