# 利用ガイド

Sesami Wear の初期設定から日常操作までをまとめたガイドです。インストール手順は
[INSTALL.md](INSTALL.md)、アップデート内容の確認先や問い合わせ方法は [SUPPORT.md](SUPPORT.md) を
参照してください。

> 本アプリは個人による非公式アプリであり、CANDY HOUSE株式会社とは提携・協力関係にありません。
> 動作保証・サポートは同社の対象外です。

## このアプリでできること

- スマートウォッチのタイルから、Sesameスマートロックをワンタップで施錠・解錠する
- ウォッチフェイスのコンプリケーションに、現在の施錠状態を表示する
- 複数台のSesameを登録し、タイルごとに操作対象を切り替える／全台を一括操作する
- 操作の成否を、画面を見なくても分かるように振動パターンで区別する

施錠・解錠の実行はスマートフォン側のアプリが行い、ウォッチは操作の意図を送るだけです。
そのため、**ウォッチとスマートフォンが接続されている必要があります**（ウォッチ単体では操作できません）。

## 準備するもの

| 必要なもの | 補足 |
| --- | --- |
| CANDY HOUSE Sesame 5 と Hub 3 | Hub 3（クラウド経由のリモート操作）が必須です |
| Androidスマートフォン | Android 8.0（API 26）以降 |
| Wear OSスマートウォッチ | Wear OS 3以降。スマートフォンとペアリング済みであること |
| Sesame APIの資格情報3点 | uuid・apikey・secretKey（取得方法は次章） |

## STEP 1: Sesame APIの資格情報を取得する

施錠・解錠には、Sesameデバイスごとに次の3点が必要です。いずれも
[biz.candyhouse.co](https://biz.candyhouse.co/biz/developer)（SESAME Biz 開発者ページ）で確認・発行
できます。

| 項目 | 内容 |
| --- | --- |
| `uuid` | 操作対象のSesameデバイスの識別子（sesame2_uuid） |
| `apikey` | API呼び出しに使うキー（x-api-key） |
| `secretKey` | 施錠・解錠コマンドの署名に使う鍵。**16進数32文字** |

- `secretKey` は16進数32文字です。Sesameアプリの「鍵をシェア」QRコードから読み取った値ではなく、
  上記の開発者ページに表示される値を使います。
- これらは**Sesameを施錠・解錠できる情報**です。第三者へ共有しないでください。

## STEP 2: スマートフォンアプリへ登録する

1. スマートフォンで「Sesami Wear」アプリを起動します。
2. 画面上部の「ヘルプ」から、取得元のページを開くこともできます。
3. フォームへ次を入力します。
   - **表示名（任意）**: 「玄関」「勝手口」など、ウォッチ側に表示される名前
   - **uuid** / **apikey** / **secretKey (16進数32文字)**
4. 「追加」をタップします。「保存しました」と表示されれば登録完了です。
5. 2台目以降も同じ手順で追加します。画面上部に「Sesame API設定（N台登録済み）」と表示されます。

登録済みのデバイスは一覧の「編集」「削除」から変更できます。入力値が不正（未入力、secretKeyが
16進数32文字でない）な場合、「追加」ボタンは押せません。

資格情報はスマートフォン内で暗号化して保存され（`EncryptedSharedPreferences`）、ウォッチ側へは
送られません。開発者を含む第三者のサーバーへ送信することもありません（[プライバシーポリシー](store/PRIVACY_POLICY.md)参照）。

## STEP 3: ウォッチにタイルを追加する

1. ウォッチフェイスを左右にスワイプしてタイル一覧を表示し、末尾の「＋」（タイルを追加）をタップします。
2. 一覧から「Sesami Wear」を選びます。
3. 追加直後のタイルには「タップして設定」と表示されます。タップすると操作対象の選択画面が開きます。
4. スマートフォンで登録したデバイス名の一覧が表示されるので、このタイルで操作したいデバイスを
   選びます。2台以上登録している場合は「全デバイス」も選べます。

> スマートフォン側でデバイスを登録していないと、選択画面に「スマホでSesameを登録してください」と
> 表示されます。STEP 2を先に完了してください。

タイルの構成は次のとおりです。

| 位置 | 表示 | タップしたときの動作 |
| --- | --- | --- |
| 左上 | デバイス名 | 最新の状態を取得しなおす |
| 左下 | 変更 | 操作対象のデバイスを選び直す |
| 右（大きいボタン） | 状態アイコン・状態・操作ラベル | 施錠または解錠を実行する |

## STEP 4: 施錠・解錠する

- **施錠**: タイル右側をタップすると、確認なしで即座に施錠します。
- **解錠**: タイル右側をタップすると確認画面が開きます。左の「キャンセル」／右の「解錠」を選びます。
  誤操作で解錠されることを防ぐため、施錠と非対称の設計にしています。
- 実行結果は振動で通知されます。成功と失敗で振動パターンが異なるため、画面を見なくても区別できます。
- 連続タップによる二重送信は、スマートフォン側で2秒以内の同一デバイスへの重複コマンドを無視すること
  で防いでいます。

「全デバイス」を選んだタイルでは、ボタンのラベルが「タップで全施錠」「タップで全解錠」になり、
登録済みの全デバイスへ順に操作を送ります。

## 表示の意味

タイルの状態表示は次のとおりです。

| アイコン | タイルの表示 | コンプリケーションの表示 | 意味 |
| --- | --- | --- | --- |
| 🔒 | 施錠中（全施錠中） | 施錠 | 施錠されています |
| 🔓 | 解錠中（全解錠中） | 解錠 | 解錠されています |
| 🔀 | 施錠/解錠混在 | 混在 | 「全デバイス」選択時に、施錠と解錠が混在しています |
| ⏳ | 通信中... | 通信中 | コマンドを送信中です |
| 📵 | スマホ未接続 | 未接続 | スマートフォンと接続できていません。操作できません |
| ❔ | 状態不明 | 不明 | 状態をまだ取得できていません |

🔀（混在）のときにタイルをタップすると、安全側に倒して「全施錠」を実行します。

## コンプリケーション（文字盤への状態表示）

ウォッチフェイスの空き枠へ、現在の施錠状態を常時表示できます。

1. ウォッチフェイスを長押しし、「カスタマイズ」からコンプリケーションの枠を選びます。
2. データソースの一覧から「Sesami Wear」を選びます。
3. 選んだ直後にデバイス選択画面が開くので、その枠で表示したいデバイス（または「全デバイス」）を
   選びます。
4. 割り当て済みの枠をタップすると、デバイスを選び直せます。

- 枠のサイズによって、状態のみ（例: 施錠）と、デバイス名＋状態（例: 玄関 施錠）を出し分けます。
- コンプリケーションは**表示専用**です。タップしても施錠・解錠は実行されません（設定画面が開きます）。
  操作はタイルから行ってください。

## 状態表示が更新されるタイミング

本アプリは電池消費を抑えるため、定期的な状態の問い合わせ（ポーリング）を行いません。表示は次の
タイミングで更新されます。

- タイルやコンプリケーションを表示したとき（前回取得から30秒以上経過している場合、最新状態を
  取得しなおします）
- タイルの**デバイス名部分をタップ**したとき（手動での更新）
- 本アプリから施錠・解錠を実行し、成功したとき

このため、**Sesame純正アプリや物理的な操作でロック状態が変わった場合、次の更新まで表示へ反映され
ません**。最新の状態を確認したいときは、タイルのデバイス名部分をタップしてください。

## 困ったときは

| 症状 | 確認すること |
| --- | --- |
| タイルに「スマホ未接続」と出る | ウォッチとスマートフォンのBluetooth接続を確認してください。Wear OSアプリで接続状態を確認できます |
| タイルに「タップして設定」と出たまま | タップして操作対象のデバイスを選んでください |
| デバイス選択画面が「スマホでSesameを登録してください」になる | スマートフォン側でSTEP 2の登録を行ってください。登録直後は反映に少し時間がかかる場合があります |
| 操作すると失敗の振動が返る | 資格情報（特にsecretKey）の入力誤り、Hub 3のオフライン、通信環境をご確認ください。スマートフォンのSesami Wearアプリで登録内容を確認・再入力できます |
| 状態表示が実際と違う | 上記「状態表示が更新されるタイミング」を参照し、タイルのデバイス名部分をタップして更新してください |
| コンプリケーションが空欄のまま | 枠をタップしてデバイスを割り当ててください。文字盤によっては表示形式が対応していない場合があります |
| 施錠・解錠が反応しない | 2秒以内の連続操作は重複として無視されます。少し待ってから再操作してください |

解決しない場合は [SUPPORT.md](SUPPORT.md) の手順で報告してください。報告の際は、
**apikey / secretKey / uuid を含めないよう**ご注意ください。

## 資格情報を削除する

次のいずれの方法でも、端末に保存された資格情報を削除できます。

- スマートフォンのSesami Wearアプリで、一覧から「削除」をタップする
- Android設定の「アプリ情報」からアプリのデータを消去する
- アプリをアンインストールする

Sesame側の鍵を無効化したい場合は、biz.candyhouse.co で該当の鍵を再発行・失効させてください。
